# Phase 5 proposed consent interface — counsel review

Status: proposal only. Not published; no live privacy-policy text changed. Equal-weight Accept/Decline buttons, white panel with existing blue/dark typography and visible focus; both actions have the same size, fill and prominence. Necessary is always enabled; analytics and advertising are separately optional/off until a valid choice. Preferences can be reopened from the footer.
